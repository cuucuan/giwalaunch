How GiwaLaunch works

  • Config first: the launchpad registers an immutable Config (fees, recipients, graduation policy) in the Ammora Config Registry. GiwaLaunch Config #76 uses concentrated graduation with a 0.0005 WETH quote threshold and zero base threshold.
  • Issue: a creator launches a token + pre-graduation bonding curve (ALC) in one transaction through the Launch Factory.
  • Trade: buys and sells run on the curve against WETH with a 125 bps cliff fee; every quote is simulated before signing.
  • Graduate: once the quote threshold is crossed, migration moves liquidity into a concentrated ARL pool and trading continues there.
  • Fees: Creator and Partner claim their shares separately from the FeeVault; LP fees accrue to position owners.
